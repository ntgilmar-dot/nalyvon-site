# Nalyvon — site institucional v0.1

Versão estática pronta para hospedagem gratuita no Render, sem etapa de build.

## Arquivos
- `index.html`: site completo
- `styles.css`: sistema visual e responsividade
- `assets/nalyvon-symbol.png`: B3.1 oficial
- `render.yaml`: configuração de deploy

## Publicação no Render
1. Criar um repositório exclusivo para este site.
2. Subir o conteúdo desta pasta na raiz do repositório.
3. Render > Static Site.
4. Build command: `echo "Static site ready"`
5. Publish directory: `.`

## Pendente antes de divulgar
- Definir e-mail/WhatsApp/formulário oficial de contato.
- Conectar domínio próprio, se desejado.
- Adicionar política de privacidade somente quando houver coleta de dados.

## Fonte de verdade
A identidade visual deve permanecer B3.1 — Força Fluida, com #0B0C0E, #002347, #D09E57 e #F6EDE4.
