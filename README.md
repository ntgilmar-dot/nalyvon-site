# Nalyvon

Site institucional estático. Fonte publicada única: public/. Sem build, dependências de runtime ou cópias entre pastas.

## Render existente

Serviço: nalyvon-site (srv-db31k949v7es73albcc0). Branch main, diretório raiz vazio, build command: echo "Static site ready", publish directory: public. A configuração do serviço existente deve corresponder a render.yaml; o arquivo sozinho não atualiza um serviço criado manualmente.

## Marca

Originais mais recentes identificados pelos nomes oficiais e histórico do repositório: brand-source/. Assets web: public/assets/brand/. Lockup composto com os pixels dos originais, sem fonte substituta. Símbolo com máscara externa, preservando RGB e proporção; sem geração de imagem. Favicon quadrado com respiro.

Reproduzir os derivados na raiz com Windows PowerShell 5.1: powershell.exe -NoProfile -File tools/derive-brand.ps1. O script não participa do deploy.

Limitação da fonte: o símbolo raster original já toca a borda inferior. Não foi reconstruída a curva ausente. Não existe master vetorial no repositório.
